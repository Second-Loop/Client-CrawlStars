# 팀전 사망 후 아군 관전

## 전체 흐름

1. 스냅샷에서 내 사망을 먼저 확인해요.
2. 입력과 로컬 이동 예측을 즉시 중단해요.
3. 사망한 플레이어 객체를 풀에 반환해요.
4. 살아 있는 아군을 선택하고 카메라와 부쉬 시야를 옮겨요.
5. 팀의 `GameEnd`를 받을 때까지 스냅샷 수신을 계속해요.

## 관전 대상 선택

- 살아 있는 내 캐릭터가 있으면 계속 자신을 따라가요.
- 내가 사망하면 현재 관전 대상이 살아 있는 동안 그 대상을 유지해요.
- 새 대상을 고를 때는 같은 팀의 생존자를 `Slot` 오름차순으로 정렬해요. `Slot`이 같으면 ID의 ordinal 순서로 선택해요.
- 적, 사망자, 내 캐릭터는 관전 대상으로 선택하지 않아요.
- 생존 아군이 없으면 카메라 대상을 비우고 팀 결과를 기다려요.
- 사망 상태는 매치가 초기화될 때까지 유지해요. 나가기 팝업을 취소해도 입력이 다시 활성화되지 않아요.

## 화면과 시야

- 관전 중에는 `Spectating teammate`를 표시하고 조준선과 쿨타임 UI를 숨겨요.
- 생존 아군이 없으면 `Waiting for team result`를 표시해요.
- 부쉬 안의 적을 볼 수 있는지는 현재 관전 중인 아군 위치로 계산해요.
- 카메라 대상이 없으면 부쉬 안의 적을 새로 드러내지 않아요.

## 생명주기

- `PlayerManager.Initialize`와 `ClearListeners`가 관전 상태를 초기화해 다음 매치로 남지 않게 해요.
- 입력을 비활성화할 때 진행 중인 조준 버튼, 공격 방향, 스킬 종류를 함께 지워 다음 매치 입력에 남지 않게 해요.
- 부쉬 시야 때문에 비활성화된 플레이어도 풀 큐에 아직 없다면 정상 반환하고, 실제 큐에 든 객체만 중복 반환으로 거부해요.
- 서버의 기존 `GameEnd` 처리와 씬 이동 흐름은 그대로 사용해요.
