# SL-124 팀전 개인 사망 후 관전

사용자가 SL-123 댓글과 Codex 대화에서 팀전 개인 사망 후 관전, 팀 종료 때 공동 결과 수신을 확정했어요.

- 개인 사망은 서버 GameEnd를 만들지 않아요. GameEndReceived의 기존 결과 흐름을 유지해요.
- 사망한 내 캐릭터가 pool에 반환되면 MyListener와 카메라 참조를 해제해요. 로컬 이동 예측·공격·조준 입력을 중단하고 나가기 취소로 재활성화되지 않게 해요.
- 생존 아군을 Slot 오름차순, 동률이면 ID ordinal 오름차순으로 선택하고 현재 대상이 살아 있으면 유지해요. 대상 사망 시 다음 대상으로 전환해요. 살아 있는 내 캐릭터가 있으면 자신을 따라가요.
- 생존 아군이 없으면 카메라 target을 해제하고 서버 결과를 기다려요. 없는 객체를 참조하지 않아요. solo/duel의 서버 결과 규칙은 유지해요.
- 부쉬 시야는 관전 대상의 위치를 기준으로 계산해요. 대상이 없으면 적을 추가로 드러내지 않는 안전한 처리로 가요. 현재 자신의 팀 판정은 유지해요.
- 관전 중에는 기존 infoText 등에 'Spectating teammate' 같은 짧은 상태를 표시하고 전투 조준·쿨타임 UI를 숨겨요. 새로운 scene/prefab 구조는 만들지 않아요.
- 매치 초기화/종료 때 사망·관전 상태를 초기화해 다음 매치에 남기지 않아요.
- scope: 클라이언트 관전만. 전투 상태 DTO/쿨타임·새 액션 계약·config·서버 파일은 다음 작업에서 다뤄요.
- Unity 6000.3.15f1 Editor는 현재 미확인. 실제 Unity 테스트 실행 없이 Pass라고 표시하지 않아요. 순수 상태 로직은 독립 C# 하네스로 검증 가능해요.
